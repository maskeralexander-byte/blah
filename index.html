PWR Live: analyze the live page as it updates

Read-only

A bookmark that opens this analyzer as a panel on top of pwr.dominos.com. It reads the Real Time Sales table every few seconds and shows pace against last year, projected end-of-day sales, and stores that slow down or stop reporting. It only reads what's on your screen. It never clicks, changes, or sends anything. Nothing to install.

On your phone (Chrome on Android)

  1. Tap Copy bookmark code below.
  2. In Chrome, open any page, tap ⋮, then the ☆ star. Tap Edit in the bar that pops up (or find it later under ⋮ › Bookmarks, press and hold it, and choose Edit).
  3. Change the name to PWR Live. Delete everything in the URL box, paste the code, and save. It should start with javascript:
  4. On any pwr.dominos.com page (the sign-in page is fine), tap the address bar, type PWR Live, and tap the bookmark (★) in the suggestions. Opening it from the Bookmarks list won't run it; it has to be from the address bar.
  5. Sign in and move around PWR as usual. The panel stays open; tap – to tuck it away or × to leave.

On a computer

  1. Drag this button to your bookmarks bar: PWR Live
  2. Or copy the code and paste it as a new bookmark's URL.
  3. On any pwr.dominos.com page, click the bookmark. The panel stays open while you sign in and move around PWR.

When it works, a "PWR Live" panel slides up within a few seconds. If you see a message that it couldn't load, your network blocks the site the code is loaded from (cdn.jsdelivr.net); use the instead (about 29 KB; works on computers, may be too long for phones). If nothing happens at all, the bookmark didn't run: check that the URL starts with javascript: and that you opened it from the address bar.

Your targets are built into the bookmark. If you change them under Targets, copy the code again and update the bookmark.

Column mapping

The analyzer matched your report's columns automatically. Fix any that are wrong or missing. Times like 24:35 are read as minutes:seconds; $, % and commas are ignored. Rows labeled Total are skipped so they don't double-count.

Targets

Defaults are common starting points. Set them to your franchise or district goals; they're saved in this browser.
